Lapu-Lapu City, Cebu, Philippines

Abiso /ah-BEE-so/, notice

Brownouts, water cuts, class suspensions and weather warnings come from different offices, posted in different places. Abiso reads each official notice once, turns it into a dated event for your barangay with a link to the source, and answers in Cebuano, Filipino or English.

How it works

    
    
      
  1. Every few hours Cloud Scheduler asks the service to read the issuers' sites: MECO (power), MCWD (water), DepEd Lapu-Lapu, PAGASA, and the city.
    2. 
      
  2. Each new post is compiled once by Gemini into a typed event: what, which barangays, from when to when, status, and the source link. Posts that extend or cancel an earlier notice are merged into it.
    3. 
      
  3. Events live in Firestore. This page, the agent, MCP and A2A all read them through the same functions, so every door gives the same answer.
    4. 
      
  4. When there is no official notice, Abiso says so. It never guesses.
    5. 
    

    

  


  

    Built with Gemini on Vertex AI, Google ADK, Cloud Run, Cloud Scheduler and Firestore.
